# WP007L GitHub forensic tool landscape

Research date: 2026-09-19. Exact commits are pinned in the adjacent JSON. GitHub popularity was not treated as scientific evidence.

## Decisions

`jpegio` and `jpeglib` are adoption candidates for isolated coefficient-level inspection. Both were imported and used as bounded oracles on real controlled files; the Lythaus parser remains the recorded authority for current-byte facts until a broader fixture suite is complete.

`ZERO` was cloned at the pinned commit, compiled with the existing WSL GCC/libjpeg/libpng/libtiff toolchain, and invoked on a controlled camera source/descendant pair. It remains an AGPL research oracle; no source was copied. `Sherloq` remains GPL research-only because it is a GUI-oriented educational toolkit with broad feature claims and no production-grade contract.

`c2pa-rs` is the strongest candidate for a future provenance-only integration. It must remain separate from JPEG/AI-origin inference. The archived `c2patool` repository is not a new dependency; it is only a reference to the maintained successor CLI.

ExifTool is valuable as an independent metadata oracle but is not currently available as an executable in the approved Windows runtime. PNU-Matlab is useful as a PRNU reference, but MATLAB is not a desired production dependency.

Additional GitHub capability searches found small double-JPEG repositories (`csjinxie/Double-JPEG-compression-detection` and `btlorch/reliable-jpeg-forensics`). Their source descriptions are relevant, but neither exposed a verified repository licence in the pinned audit; they remain research references, not dependencies.

## Licence firewall

GPL/AGPL tools were inspected and, where practical, executed only as external oracles. No GPL/AGPL source was copied into Lythaus-owned modules. Permissive licences still require pinned commits, dependency notices, and a separate deployment-rights review.

## Scientific limitation

No repository README is treated as validation. Every capability is marked with the actual local test state in `github-forensic-tool-landscape.json`; unsupported capabilities remain context-only or blocked rather than promoted by description.

Official repositories: [jpegio](https://github.com/dwgoon/jpegio), [jpeglib](https://github.com/martinbenes1996/jpeglib), [Sherloq](https://github.com/GuidoBartoli/sherloq), [ZERO](https://github.com/tinankh/ZERO), [PNU-Matlab](https://github.com/DIFLabUnisa/PNU-Matlab), [ExifTool](https://github.com/exiftool/exiftool), [c2pa-rs](https://github.com/contentauth/c2pa-rs), and [c2patool](https://github.com/contentauth/c2patool).
