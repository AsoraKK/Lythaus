# WP007N independent pre-extraction audit

2026-09-19; isolated WP007N worktree.

**Disposition: BLOCKED for extraction on the audited snapshot; three P1 defects.** These are implementation/admission defects, not evidence that leakage, overspending, or scientific extraction has already occurred. P1 means correct before extraction; P2 means a validation/reporting gap requiring disposition. No code changes were made.

Scope: the three requested scripts, active cohort/protocol/seal JSONs, and engineering A/B JSONs. No literature reread, reserve files, media, models, upstream datasets, runtime caches, or fitting/test implementation were inspected. Validation used text/JSON, standard-library arithmetic, AST syntax checks, and isolated pure role/request functions. The path checker was stubbed in role-validation probes, so these probes made no external filesystem accesses.

## Findings

1. **P1 — Forward/time budgets are not failure-safe.** [wp007n_extract.py:103-123](../../scripts/authenticity/wp007n_extract.py#L103) checks only whether the existing count has reached its limit, then can execute four forwards. For example, 899 recorded forwards passes a 900 limit check and the response ends at 903. More seriously, `forwards += 4` runs only after `response()` returns; an exception after one or more internal forwards leaves all those attempts uncounted ([wp007n_core.py:133-141](../../scripts/authenticity/wp007n_core.py#L133)). Budget persistence occurs only in `finally` ([extract:141-149](../../scripts/authenticity/wp007n_extract.py#L141)); abrupt termination can retain completed parent caches while losing the corresponding charges. Restart then skips those parents. Initialization also precedes the budget gate ([extract:68-76](../../scripts/authenticity/wp007n_extract.py#L68)), and a four-forward call can overrun the remaining time. Required: persist reservation/accounting before each charged forward, count ambiguous/failed attempts, check remaining capacity and elapsed time between calls, and reconcile interrupted runs before resuming. Limits: [protocol.json:13,17](protocol.json#L13). The nominal workload fitting inside the cap does not repair these failure modes.

2. **P1 — Evaluation admission accepts stale or empty calibration files.** [wp007n_extract.py:54-58](../../scripts/authenticity/wp007n_extract.py#L54) requires five filenames to exist but never reads or validates their contents. Empty JSON or calibration from an earlier protocol, head, cohort, or preprocessing contract therefore passes this gate before evaluation images are processed. This fails the frozen-before-evaluation requirement in [protocol.json:12](protocol.json#L12) and [protocol-hash.json:5-6](protocol-hash.json#L5). Required: validate each candidate's schema, finite thresholds, calibration parents/role, protocol/cohort identity, and fitted-head identity before evaluation; reject incomplete or stale calibration. The fitter is being implemented separately and was not audited; this finding concerns the extractor's independent gate.

3. **P1 — Cache admission does not bind the executed instrument or validate record identity.** [wp007n_extract.py:79-85](../../scripts/authenticity/wp007n_extract.py#L79) binds declared preprocessing, checkpoint, cohort, protocol and a fixed version string. It neither includes the actual source hashes in the key nor checks them on reuse, although they are recorded at [extract:135](../../scripts/authenticity/wp007n_extract.py#L135). A noise/transform/scoring bug fix with unchanged declarations reuses old features/responses, while newly extracted parents can use the revised code. The cache-hit path checks only the array-file hash and key; record roles, labels, request completeness, per-feature hashes and source/identity metadata are not validated. `freezes()` also verifies no executable-code hash ([extract:19-29](../../scripts/authenticity/wp007n_extract.py#L19)). Required: freeze and enforce the execution contract, invalidate stale caches, and validate cached record/array structure against the expected parent and requests. Existing metadata merely recording hashes does not enforce them.

4. **P2 — Role/rights validation is weaker than the frozen protocol.** [wp007n_freeze.py:38-58](../../scripts/authenticity/wp007n_freeze.py#L38) has no role/label schema, negative-only calibration rule, required group identity, or rights-class check beyond `trainingAllowed`. Isolated probes of this exact function accepted an unknown role, a synthetic `CALIBRATION` row, a missing `rights` value, and a missing `splitGroup`. CLI roles are also unrestricted text ([extract:154-158](../../scripts/authenticity/wp007n_extract.py#L154)); an unknown requested role silently selects no rows after initialization. In freeze construction, rights booleans are assigned rather than universally inherited, and `sealed` is unconditionally reset to false ([freeze:83,96,102,110-123](../../scripts/authenticity/wp007n_freeze.py#L83)); camera records explicitly exclude `finalSealedControl`, while the DDB membership map does not apply that same filter ([freeze:66,85-86](../../scripts/authenticity/wp007n_freeze.py#L66)). Required: enforce exact admissible roles/labels/populations, preserve and reject inbound exclusion flags, and bind rights decisions to approved source receipts. **No forbidden training placement or reserve access was observed in the current cohort metadata.** Source grants and prior-manifest membership remain outside this bounded audit, so this is not a finding that existing rights are invalid.

5. **P2 — Nonfinite perturbed outputs do not trigger the declared immediate stop.** [wp007n_core.py:133-141](../../scripts/authenticity/wp007n_core.py#L133) computes noisy embeddings and similarities without finite checks; [wp007n_extract.py:124-130](../../scripts/authenticity/wp007n_extract.py#L124) validates only the clean embedding. A nonfinite perturbation result can consume the rest of the parent's requests before `allow_nan=False` rejects its metadata serialization ([core:51-56](../../scripts/authenticity/wp007n_core.py#L51), [extract:131-135](../../scripts/authenticity/wp007n_extract.py#L131)). The NPZ has already been renamed by then. This ultimately fails rather than silently serializing NaN, but violates the immediate nonfinite-output stop and wastes bounded attempts. Required: validate every noisy embedding, similarity and aggregate before further inference or cache publication. Rule: [protocol.json:17](protocol.json#L17).

6. **P2 — Derived-byte admission is declared but unenforced.** [protocol.json:13](protocol.json#L13) caps derived data at 100,000,000 bytes. [wp007n_core.py:69-75](../../scripts/authenticity/wp007n_core.py#L69) checks only free RAM/disk, while [wp007n_extract.py:66-69,131-135](../../scripts/authenticity/wp007n_extract.py#L66) creates cache artifacts without a derived-byte ledger or cap check. Current nominal feature payload is only 2,228,224 bytes, so this is not an observed size overrun; metadata, partial files and stale cache generations still lack enforcement. Required: account for active derived artifacts and enforce the declared bound before writes.

### Remaining material defects

- **P1-R1 — PID inspection is not atomic ownership.** Both constructors can read the same inactive ledger at [guards:103-104](../../scripts/authenticity/wp007n_guards.py#L103) before either persists its active PID at [123-124](../../scripts/authenticity/wp007n_guards.py#L123). The later PID check therefore never runs for either opener. An in-memory interleaving of the exact class admitted two instances with a one-forward cap; both reserved an attempt, while last-writer persistence recorded only one. No forwards were executed. Acquire exclusive same-arm ownership atomically before reading/recovering the ledger, retain it through finish, and fail closed on uncertain liveness. Per-forward reservation otherwise fixes the earlier ordinary-exception undercount.
- **P1-R2 — A successful replay certificate can authorize a different target execution.** The legacy branch at [guards:68-78](../../scripts/authenticity/wp007n_guards.py#L68) checks the replay boolean, allowed parent role, old file hash and old code hashes, but ignores certificate `executionSignature`, `cohortHash`, schema and replay-panel evidence. An isolated execution of this admission prefix accepted a certificate with `OLD-SIGNATURE` and a wrong cohort when asked to admit `NEW-SIGNATURE`. Later feature/record checks do not bind that replay to the new code. Require exact certificate-to-current signature/cohort binding, verified replay evidence and receipt integrity; invalidate or explicitly recertify after further code changes. A fresh extraction is not automatically required merely to repair this gate.
- **P1-R3 — Hash integrity still substitutes for semantic head/calibration validation, and analysis code is unsealed.** Exact `load_candidate()` plus `validate_calibrations()` accepted in-memory, hash-consistent fixtures with A0 assigned a B backbone, one-dimensional zero-scale parameters, reversed class order and contradictory finite thresholds (`original=9`, `worst=-9`, all recorded source maxima `0.1`). Enforce expected candidate/backbone/feature-key/permutation mapping, dimensions, strictly positive scales, class order and calibration threshold/maxima invariants. The current four-file execution seal excludes `wp007n_analysis.py` ([execution-code-freeze.json:2-6](execution-code-freeze.json#L2)); calibration's recorded `codeHash` is not enforced and heads have no checked scoring-code identity ([analysis:128,152,192-201](../../scripts/authenticity/wp007n_analysis.py#L128), [guards:24-42](../../scripts/authenticity/wp007n_guards.py#L24)). Seal and validate the actual fitting/scoring/calibration implementation before head admission. These probes establish acceptance gaps, not that the real heads are malformed.
