# Recommended next experiment

## One primary experiment

**SAFE-B frozen-backbone compression/domain probe**

1. Install only the official SAFE runtime in an isolated research environment after a separate resource check.
2. Extract the frozen 512-dimensional pre-classifier representation for WP007I controls, SAFE-easy positives, Seedream-4, Imagen-4, public FLUX.1, and already-consumed Cloudflare FLUX.1.
3. Run descriptive family-centroid and nearest-neighbour analyses without fitting a detector.
4. If the representation contains separable missed-generator information, fit only a tiny linear head in a new package using rights-cleared data and family-held-out splits.
5. In parallel, construct actual-codec clean/degraded pairs using at least two encoders and exact table manifests.
6. Compare SAFE-A, SAFE-A degraded, and SAFE-B on clean specificity, hard negatives, per-generator recall, JPEG table/encoder regimes, and transformations.

## Alternatives

- If the SAFE representation does not contain missed-generator information, evaluate a CPU-feasible phase/DCT specialist rather than a SAFE head.
- If the phase/DCT measurements are stable but weak alone, keep them as EF4 applicability/context and do not turn them into authenticity evidence without independent evaluation.
- If rights or compute block neural work, implement only the deterministic JPEG inspector and retain SAFE as a positive specialist with a stricter evidence-grade input boundary.

## Why this is highest value

It directly tests whether SAFE's blind spots are in the frozen head or in the representation, addresses JPEG and unseen generators with one controlled protocol, preserves SAFE-A as a reference, and avoids a new detector zoo or full training commitment.
