# One next experiment — static versus response information

**Hypothesis, not established evidence:** a frozen, already-approved non-SAFE visual representation may contain origin information in its response to controlled perturbations that is absent from its static representation. This differs from replacing SAFE's failed head and from repeating K's marginal statistics or M's scalar. No execution is authorized by this recommendation alone.

Use an existing locally cached RINE backbone only if its exact weights, extraction point, licence and CPU memory budget permit private evaluation. Otherwise stop; do not replace it with an unbounded download. Do not promote RINE's existing classifier or fit a fusion model. Previous supporter failure is a reason for a strict falsifier, not grounds to assume a new response signal.

Before measurement, freeze one response statistic: cosine displacement of a unit-normalized frozen embedding under two mild deterministic transforms, relative to its repeat-extraction numerical baseline. Compare to the original static embedding/score on the **same** source parents. Fix transforms/geometry in advance; record actual bytes and codec tables. Synthetic output must not set thresholds where only evaluation rights exist.

First run a maximum 100-parent discovery/falsification cohort: 40 photographs (including consumed CSAFE and diverse processed images), 40 synthetics with multiple families including Seedream/Imagen, and 20 genuine non-generative digital works. The last category must be actual rights-cleared CGI/art/game material, not renamed procedural templates. Existing media only; inability to obtain that control is a design blocker, not permission to claim specificity. These historical challenge images are development, never fresh confirmation.

Keep source/parent and generator roles; directly compare static and response distributions, matched current format/size/codec, hard-negative harm and paired transformation effects. No learned predictor, direction search or threshold sweep in this first screen. Record every tested response rather than selecting the best afterward.

**Stop/reject:** response separation is replicated by static evidence, follows encoder/size or digital-versus-photo shortcuts, disappears on either challenge family, or contradicts hard negatives. Only a reproducible residual effect on both negative categories warrants a later, separately frozen and genuinely independent family-held-out experiment. No <=1% FPR claim from 60 negatives. Any eventual decision rule needs specificity-first development, source-worst-case intervals and unique SAFE rescue at a fixed threshold.

Cap the pilot at one worker, existing CPU runtime, available RAM >=4 GiB, <=100 MiB derived storage and 30 minutes of attended inference; persist per source. No training, GPU, providers or new checkpoints. SAFE-A remains the immutable comparator; FLUX.2 and sealed devices remain untouched.

This is the smallest next information test, not a new architecture recommendation. Do not restart scalar-wavelet tuning merely because this response hypothesis is uncertain.
