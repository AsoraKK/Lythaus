# Provider decommission follow-up

This checklist separates repository decommissioning from live provider changes.
Repository automation may capture sanitized read-only provider evidence, but no
live provider resource is considered safe to delete until its current bindings,
traffic, rollback path, and replacement state have been verified.

## Repository boundary

The repository may remove obsolete code, workflows, branches and active legacy
metadata and may run sanitized provider audits. Destructive Cloudflare or
PlanetScale operations must still use current live evidence and a tested rollback
path. Historical Git commits are not rewritten solely to erase retired branding.
